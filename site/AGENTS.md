# site/

## Purpose
- The generated static SPA that ships to the host. Served as plain files; there is no backend.
- Hash-router app that reads `window.*` data bundles and lazily loads the heavy ones per route.

## Ownership
- **Generated output.** Produced by `py -3 generator/scripts/build.py .` from `generator/site-template/` plus `data/` and root config. Do not hand-edit; change the template or the data and rebuild.
- `app.js` — router, views, quiz/exam engine, concept decks (`#/kavram`), word games (`#/oyunlar`), offline page. Built from `generator/site-template/app.js`.
- `data.js` — generated: `window.UNIVERSITY`, `window.COURSES`, `window.OFFLINE`.
- `index.html`, `styles.css`, `sw.js`, `manifest.webmanifest`, `favicon.svg`, `fonts/`, `icons/` — from the template with `{{V}}` cache-bust stamped in.
- `coursegraph.js` — generated by `py -3 -m coursegraph.site_export` (`window.CG`), the browser search index.
- `past_exams.js` — generated by `py -3 scripts/export_past_exams_site.py` (`window.PAST_EXAMS`).
- `unit_quizzes.js` — generated by `py -3 scripts/export_unit_quizzes_site.py` (`window.UNIT_QUIZZES`).
- `interactive.js` — course panel data (concepts/timeline/tree); the builder does not overwrite it.
- `downloads/` — generated: browser-extension zips packed by `build.py` from `extensions/`.
- `assets/<slug>/` — course images (jpg/webp) served to the page and packed for offline use.

## Local Contracts
- Lazy bundles load per route via `LAZY_BUNDLES` in `app.js`: `interactive`, `coursegraph`, `past_exams`, `unit_quizzes`. Adding a bundle means adding it to `LAZY_BUNDLES` **and** to `SHELL_FILES` in `generator/scripts/build.py` so it is cached offline.
- Every bundle assigns to a `window.*` global; `app.js` reads them through accessor functions and falls back to an empty stub if a bundle fails to load.
- `sw.js` caches the app shell on first visit; new versions wait for the student to tap "Yenile" on the update toast. Course images are downloaded per course from the offline page.
- Learner progress lives in `localStorage[CONFIG.storageKey]`; study state (concept-deck cards, mock exams, game results) lives in `localStorage[CONFIG.storageKey + ".study"]`.
- Editor mode: opening `#/?duzenle=1` stores `localStorage[CONFIG.storageKey + ".editor"]` and shows "NotebookLM'de düzenle" (notebook on `notebook.google.com`) plus a link to `#/eklenti`; `#/?duzenle=0` clears it. Students never see these buttons.
- Data bundles are compared for duplicate detection **exactly**, preserving Ottoman Turkish diacritics.

## Work Guidance
- Rebuild after any change to `data/`, `courses.json`, `university.json`, or `generator/site-template/`: `py -3 generator/scripts/build.py .`
- Regenerate the three graph/exam bundles separately when their source data changes (see `scripts/AGENTS.md`, `coursegraph/AGENTS.md`).

## Verification
- Serve locally and smoke-test the routes: `py -3 -m http.server 8000 --bind 127.0.0.1` from `site/`, then open `http://127.0.0.1:8000/`.
- `py -3 -m unittest discover -s tests` — `tests/test_exports.py` asserts the `past_exams.js` / `unit_quizzes.js` bundle contracts.

## Child DOX Index
- None. `assets/` is generated, git-ignored course imagery (see Ownership), not a code boundary.
